# shinygenui: Generative UI for 'shiny'

Declarative, catalog-constrained generative user interfaces for 'shiny'.
Developers define a finite catalog of typed UI components; end users
converse with a large language model that composes, updates, and removes
instances of those components on a canvas through schema-validated
'ellmer' tool calls, streamed progressively into the running app. The
model never emits code: arguments are plain data validated against the
catalog, so the guardrails hold by construction.
